
This is my personal site/blog that I've build with Hugo. You can use anything from here without the need to ask for permission.

## Start new

``` bash
git clone git@github.com:FKmiura/fkmiura.xyz.git

cd fkmiura.xyz

git submodule add git@github.com:FKmiura/kmiura-hugo-theme.git themes/kmiura-hugo-theme
```
